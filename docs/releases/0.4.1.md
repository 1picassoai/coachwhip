# Coachwhip 0.4.1

The same Coachwhip as 0.4.0, now installed ready-built.

## Install in under a minute

- **The installer downloads a ready-built Coachwhip** for Apple silicon from this release's page, checks it against its SHA-256 and unpacks it into `~/coachwhip`. No Apple command line tools, no Rust, nothing to compile. It used to build from source, which took about 10 minutes and 3 GB.
- **Same paths as before.** The binaries sit where the build put them, `~/coachwhip/target/release/coachwhip` and `coachwhip-prepare`, so every command in the README and the wiki works unchanged. `coachwhip.sh` starts the chat as before.
- **Building from source is still there:** run the installer with `COACHWHIP_FROM_SOURCE=1`. The installer also falls back to it if a release has no ready-built download.

## Unchanged

- The engine, the models and the numbers are 0.4.0's. Only the version number moved; the measurements in [docs/MODELS.md](../MODELS.md) stand.

## Not tested

- macOS versions older than the one the binary was built on.

# Coachwhip 0.5.3

Mac mini M4, 16 GB, measured; your Mac and your prompt will move the numbers.

## Qwen3.6-35B-A3B with every expert on the GPU

- **A 35B that fits.** With unsloth's [UD-IQ2_M file](https://huggingface.co/unsloth/Qwen3.6-35B-A3B-GGUF) (11.5 GB), Coachwhip keeps all 256 experts of all 40 layers in GPU memory; nothing streams from the SSD while it runs. **Writing about 38 tok/s; reading a 1,500-token prompt about 300 tok/s.** The 22 GB Q4 file still runs the streaming way, at the 0.3.0 numbers.
- **Chosen by itself.** When a Qwen3.5/3.6 MoE file fits in GPU memory with 1 GB to spare, the resident mode is used; otherwise the streaming path as before. The start line is the same; no bank number is needed for a file that fits.
- **Long prompts and chats.** The conversation space is fixed at 8,192 tokens and rolls when full (the first 256 words and the newest are kept) instead of refusing. Single prompts of 7,500, 9,300 and 16,800 tokens were read on one running engine at 242, 227 and 202 tok/s.
- **The API uses your sampling.** Each request's `temperature`, `top_p`, `top_k`, `min_p` and `repeat_penalty` are honoured; a request that sends none gets Qwen's own 0.7 / 0.8 / 20 / 0, with no repeat penalty. Up to 0.5.2 the API used the engine's defaults whatever the request said; that is fixed. Temperature 0 gives the same text on every run.
- **Quality, measured once.** A four-agent CrewAI job (analyst, architect, developer, tester) writing an event-sourced order service in TypeScript, judged by 8 behaviour checks at temperature 0.7: 5, 3 and 5 of 8 over three runs. Read what it writes, and run it.

## Structure

- `crates/engine/src/arena.rs`: the engine's own GPU scratch for its kernels, allocated once and reused, so a prompt piece costs one layer's memory rather than one per layer.
- `crates/engine/src/attn_kernel.rs`: the linear-attention piece kernel does the conv, the activation and the norms once per piece in parallel passes; the sequential walk only updates each head's memory. The text is byte-identical to the word-by-word path.
- `crates/server/src/chat.rs`: the sampler chain (top-k on the GPU, then top-p, min-p, temperature) and the rolling conversation space.

## Not tested

- Prompts above 17K tokens on this build.
- Macs other than an M4 with 16 GB on macOS 26.
- gpt-oss-120b and the 80B and 122B were not re-measured on this build; their streaming path is unchanged.

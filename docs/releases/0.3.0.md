# Coachwhip 0.3.0

Mac mini M4, 16 GB, measured; your Mac and your prompt will move the numbers. Method and every figure's conditions: [docs/MODELS.md](../MODELS.md).

## Faster

- **The early guess.** While the GPU works on one layer, Coachwhip runs the router of a layer four steps ahead on the same input and reads the experts it names while the GPU is busy. A guess that would land too late is dropped instead of evicting an expert in use. Defaults `--prefetch 10 --ahead 4`; `--prefetch 0` turns it off. Answers are byte-identical with it on or off.
- **Q3_K_M recommended for the 80B**, bank 70: smaller experts read sooner, and the same bank memory holds more of them.
- Qwen3-Coder-Next, five coding prompts, 300-token cap: **Q3_K_M at bank 70, 5.4 to 5.7 tok/s** over three runs (0.2.0: 4.5); **Q4_K_M at bank 56, 4.1 tok/s** (0.2.0: 3.4). Quality on 8 hidden-test tasks: 7/8 for both files, the same as 0.2.0.

## New model

- **Qwen3.6-35B-A3B** (`qwen35moe`): Qwen's newest MoE generation. 40 layers, 256 experts, 8 used. Runs from the unsloth UD-Q4_K_M file (22 GB) at `--bank 44`: **6.2 tok/s** over the five prompts, **8/8** on the quality tasks, answers byte-identical across speed settings. Its linear attention pairs value heads with key heads differently from Qwen3-Next, and the maths was checked layer by layer against llama.cpp on the same file and prompt.
- **A thinking switch**, for models that have one: the "let it think first" box on the chat page, `--think` in the terminal, always off through the API. It only puts the model's own template text at the start of its turn.
- Bank 56 also runs the 35B at the same speed but holds 2 GB more; on 16 GB it ran out of GPU memory once on a long thinking answer. Use 44.

## Structure

- Cargo workspace: `crates/engine`, `crates/server`, `crates/cli`.
- 59 unit tests (`cargo test --release`) and two Mac checks in `tests-mac/`: answers identical across speed settings; every supported model loads. Qwen3-Coder-30B-A3B runs with the early guess too (7.6 tok/s at bank 56, one run by the tester).
- `bench/speed` and `bench/quality`: the scripts behind every number on the models page, so you can run them on your Mac.
- README: a conversation holds up to 16K tokens.

## Not tested

- Qwen3.6-14B-A3B (community cut of the 35B): same architecture, not run.
- Qwen3.5-122B-A10B: needs a split-GGUF loader and more disk; later.
- Macs other than an M4 with 16 GB.

## Risk

- The thinking switch changes the prompt bytes only for models whose template has a thinking mode; the 80B's prompt is unchanged (checked byte-identical against 0.2.0's answers).

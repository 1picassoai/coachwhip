# Coachwhip 0.4.0

Mac mini M4, 16 GB, measured; your Mac and your prompt will move the numbers. Method and every figure's conditions: [docs/MODELS.md](../MODELS.md).

## New model

- **Qwen3.5-122B-A10B** (`qwen35moe`), the biggest model Coachwhip runs on 16 GB, after a five-minute squeeze on your own Mac: `coachwhip-prepare` takes the publisher's Q3_K_M file and writes a second file beside it with each expert's gate and up matrices at Q2_K (done on the GPU) and its down matrix at Q3_K; everything else is copied as it is. 45 GB written in 5 minutes on an M4. Nothing is downloaded from us.
- **Two modes.** Exact mode uses the model's own 8 experts per word. Fast mode, `--experts 4 --parallel`, asks the router for its top 4 and lets the GPU run ahead of the CPU: about twice the speed, and the answers can differ from the full model's. Fast mode is a choice, never the default; the README says so where the command is.
- Numbers on the squeezed file at bank 32, in [docs/MODELS.md](../MODELS.md): the tester's run.

## Faster

- **The parallel path, `--parallel`.** The GPU waits on a shared event for a layer's experts instead of the CPU re-queuing each layer; the CPU never waits for the GPU inside a word. Off by default; answers identical with it on or off on the 80B and the 35B.
- **`--experts N`** asks the router for N experts per word instead of the model's own number. Fewer experts means fewer bytes per word and faster writing; the answers change, so the quality check is beside the speed on the models page.

## Fixed

- The expert banks are no longer built while a prompt is being read. On a long first prompt that could push the GPU out of memory.

## Structure

- New crate `crates/prepare`: the squeeze, streaming, so the whole model never sits in memory.
- `crates/engine/src/requant.rs`: Metal kernels that squeeze a Q3_K, Q4_K or Q5_K expert to Q2_K on the GPU, one thread per 256-weight block; the prepare step uses them.
- Vendored `candle-metal-kernels` with the Q2_K matvec fix (the upstream kernel read 4 rows per group where the shader covered 8) and the shared-event wait the parallel path needs.
- Lab switches behind `COACHWHIP_*` environment variables are off and inert; they are not part of the product.

## Not tested

- Macs other than an M4 with 16 GB; M1 to M3 will be slower.
- The 122B's sampled answers beyond 300 words.
- `prepare` on a Mac without a Metal GPU falls back to the CPU and takes about 12 minutes; not timed on this release.

## Risk

- Fast mode is a different model in practice: 4 experts where the model expects 8. The README and the chat label it; the quality numbers on the models page are the measure of what it costs.
